# Labour Code Navigator

A live reference and compliance companion for India's four new labour codes — built for **AI Academy Calicut** and **World HR Connect** by **Nissamudheen Firoz**.

Covers:

- **The Code on Wages, 2019**
- **The Industrial Relations Code, 2020**
- **The Occupational Safety, Health & Working Conditions Code, 2020**
- **The Code on Social Security, 2020**

## What's inside

- **Overview** — the four codes at a glance, key stats, and a 12-week implementation roadmap
- **Reference Library** — searchable, expandable entries per code with old-law-vs-new-code comparison tables and key provisions
- **Compliance Checker** — a salary-structure calculator (applies the 50% "wages" rule), a worker-vs-employee classifier, a fixed-term gratuity eligibility checker, and a 24-item HR policy checklist
- **Ask the Agent** — a live AI chat grounded on a condensed knowledge base of all four codes

## Viewing this app

Open `index.html` directly, or via GitHub Pages once enabled for this repository (Settings → Pages → deploy from the `main` branch).

**Note on the "Ask the Agent" chat:** that feature calls the viewer's own Claude account through the `window.claude` runtime, which is only available when the page is opened as a **published Claude Artifact**. On GitHub Pages (or any other host), the chat tab will show a graceful fallback message — the Overview, Reference Library and Compliance Checker tabs work fully everywhere. For the complete experience including live AI chat, share the Claude Artifact link instead:
https://claude.ai/artifact/EDei3tSjQyG9c8txEVpu1C
